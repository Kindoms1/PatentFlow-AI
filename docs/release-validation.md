## 已发现并修复

1. 一句话请求中“生成完整发明专利”被误提取为“完整”领域，并丢失原始技术主题。现在优先保留显式主题和原始要求，后续继续使用最近的用户主题。
2. DeepSeek V4 默认思考模式与网关仅保存正文/工具调用的会话契约不兼容；对官方 V4 接口显式使用非思考模式，并改善输出上限错误提示。
3. 模型未完成特征比对时，不能仅凭较低字面重合度给出低风险结论；现在显示未评估。
4. Worker 请求体边界、门禁配置校验、取消传播和 token 上限约束补充回归测试。
5. 正式部署辅助脚本改为只读取单独的 `.env.production.local`，避免上传开发测试密钥。
